import FacadeNote from '../../components/FacadeNote.astro';

Pass a local path as the store. CiteNexus keeps its index (vectors, manifests,
provenance) under that directory. Ingest individual files, raw text, or a URL.

<FacadeNote>
	<p>
		File ingest specifically: the ports do have one, but it is <strong>native-only</strong> — Go
		behind the <code>citenexus_ffi</code> build tag, JavaScript on the
		<code>@muthuishere/citenexus/ingest</code> subpath, both needing the Rust cdylib. Neither
		reaches it from a plain <code>go get</code> / <code>npm install</code>, and neither has an
		<code>ask()</code> over the resulting store, so there is no port version of this page's flow.
	</p>
</FacadeNote>

```python
from citenexus import CiteNexus

rag = CiteNexus("./citenexus-data", embedder=..., generator=...)

rag.ingest("contracts/nda.pdf")              # PDF, DOCX, PPTX, XLSX, HTML, MD, CSV, TXT
rag.ingest(text="Clause 4: 90 days notice.", document_id="clause-4")
```

The local path is the **store** — where the index is written — not a folder that
gets auto-scanned. Each source is ingested individually — there is no
"ingest this folder" call. Ingest is idempotent by **content hash**: the manifest
records a SHA-256 per `document_id`, and re-ingesting that id with identical bytes
returns `status="unchanged"` and does no work. Re-running your ingest script only
processes what actually changed.

See [Ingest anything](/citenexus/ingest/) for the full intake surface (including
`crawl()`), or switch to [S3-native storage](/citenexus/s3/) for a shared bucket.
