prevent; it is here because a docs set that only lists wins is not a docs set you

## The shape every scenario shares

```python
from citenexus import CiteNexus
from citenexus.embed.client import OpenAICompatibleEmbedding
from citenexus.answer.generator import OpenAICompatibleGenerator

rag = CiteNexus(
    "./citenexus-data",                        # a local directory, or s3://bucket
    embedder=OpenAICompatibleEmbedding(
        base_url="http://localhost:11434/v1", model="bge-m3"),
    generator=OpenAICompatibleGenerator(
        base_url="http://localhost:11434/v1", model="qwen2.5"),
)
```

Nothing is bundled. Every model is an injected OpenAI-compatible endpoint, so
the same code runs against Ollama on your laptop, a self-hosted vLLM inside your
VPC, or a hosted API — which is what makes an EU-sovereign or air-gapped
deployment a configuration choice rather than a fork.
