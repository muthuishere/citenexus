**The failure this prevents:** a reviewer asks "can they subcontract without
consent?", the model produces a fluent paragraph, and no clause in the agreement
actually says it. The answer looks identical to a correct one.

1. **Ingest the agreement set.** PDFs keep their page number, so every later

   from citenexus.answer.result import Decision

package main

import (
	"fmt"

	"github.com/muthuishere/citenexus/golang/answer"
)

func main() {
	clauses := []answer.Doc{
		{DocumentID: "msa", Text: "The Supplier shall not subcontract any part of the Services without the prior written consent of the Customer."},
		{DocumentID: "dpa", Text: "The Processor shall notify the Controller without undue delay after becoming aware of a personal data breach."},
	}

	res := answer.Ask(clauses, "May the supplier subcontract without our written consent?", answer.DefaultTopK)
	if res.Evidence.Decision == "answered" {
		fmt.Println(res.Answer)
		fmt.Println(res.Sources[0].Document, "page:", res.Sources[0].Page) // page is nil
	}

	// No clause covers this, so the flow refuses and cites nothing.
	miss := answer.Ask(clauses, "What is the liability cap for consequential damages?", answer.DefaultTopK)
	fmt.Println(miss.Evidence.Decision, "|", miss.Answer, "| sources:", len(miss.Sources))
}
```

msa page: <nil>

```

## Why the quote is not a paraphrase

The quoted sentence in every tab above is **verbatim from the source**, not a paraphrase. That is
deliberate: a paraphrased quote is no longer evidence, and a reviewer who cannot
diff the quote against the page cannot defend the answer.

<Aside type="note" title="How precise the citation is today">
A citation resolves to **document + page + the verbatim passage** — enough to
open the page and find the sentence by search. `SourceRef.bbox` exists on the
model and PDF extraction does capture bounding boxes, but the box is **not
carried onto `Result.sources`**: on the answer path `src.bbox` is always `None`.
Do not build a viewer that expects to highlight a rectangle.
</Aside>

## Reading the signals

The signal names are the same in all three — `EvidenceSignals` is one of the
conformance-pinned shapes, so a reviewer reads the same four fields whichever
port produced the `Result`.

<Tabs syncKey="lang">
<TabItem label="Python">
```python
sig = response.evidence
sig.decision                     # answered | refused | partial
sig.distinct_documents           # how many DIFFERENT documents support this
sig.unsupported_claims_removed   # sentences dropped for lacking support
sig.all_claims_verified          # False means the answer was trimmed
```
</TabItem>

`unsupported_claims_removed` is the one reviewers care about most. An answer is
verified **per atomic claim**: if the model produces two sentences and only one
is supported by the cited clause, you get the supported sentence and a count of
what was dropped — not a fluent paragraph that is 50% invented.

<Aside type="caution" title="Reordering is not support">
A passage containing every word of a claim does **not** support it. "The Customer
shall indemnify the Supplier" and "The Supplier shall indemnify the Customer" are
the same bag of words and opposite obligations. The gate requires the claim's
tokens in **order**, and requires any negation in the matched span to survive
into the claim — so a dropped "not" is rejected rather than quoted back at you.
</Aside>

## Scoping to one matter

Isolation between matters comes from the **partition**, and from nothing else. A
`CiteNexus` instance is bound to one `PartitionPath` at construction; its vector
index, manifests and evidence all live under that leaf, so a question asked on
one matter's client cannot reach another matter's paper.

<Tabs syncKey="lang">
<TabItem label="Python">
```python
from citenexus import CiteNexus
from citenexus.domain.partition import PartitionPath

matter = CiteNexus(
    "s3://firm-corpus",
    partition=PartitionPath.of(("matter", "4471")),
    signals=["embedding", "text"],
)
matter.ingest("msa.pdf")
```
</TabItem>
<TabItem label="Go">
Go has **no partition, no storage layer and no `acl` field** — there is nothing
to isolate, because the port never holds your corpus. The `[]answer.Doc` slice
you pass to `Ask` *is* the scope: build it from the one matter the caller is
entitled to, and the isolation is your slice.
</TabItem>
<TabItem label="JavaScript">
JavaScript has **no partition, no storage layer and no `acl` field** — same
reason as Go: the corpus is the array you pass in. Scoping a question to one
matter means passing only that matter's documents.
</TabItem>
</Tabs>

One client per matter. Route the request to the instance whose partition the
caller is entitled to, and the entitlement check stays in your application —
where it can see your identity system.

<Aside type="danger" title="`acl=` does not isolate anything">
`rag.ingest(..., acl=[...])` is **carried metadata, not enforcement.** The value
is written onto `EvidenceUnit.acl` and read by no retrieval, answer or access
code path — passing `acl=["matter-4471"]` does **not** stop a query from citing
that document. It exists so you can carry your own labels through to a filter you
apply yourself. If you need confidentiality between matters, it must come from
the partition above.
</Aside>

See [Access & partitions](/citenexus/access/) for the full contract, including
what the library deliberately does not enforce for you.

## When the wrong paper is cited

A clause quoted verbatim from a superseded draft, or from the counterparty's
template instead of the executed MSA, passes the gate — the words really are
there. Rank the versions at ingest and let strict mode refuse below the floor:
see [Authority — grounding is not standing](/citenexus/authority/).

## Where this goes wrong

- **A clause split across a page break.** Chunking respects structure, but a
  clause whose operative sentence straddles pages can be cited to the page
  holding the sentence, not the clause heading. Check `src.page` against the
  clause number in the quote.
- **Definitions.** "Services" may be defined 40 pages earlier. The answer cites
  where the obligation is stated, not where its terms are defined — ask the
  definition as its own question.
